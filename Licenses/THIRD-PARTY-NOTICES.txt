Load order / runtime prerequisites
Libs/LibStub.lua
Libs/CallbackHandler-1.0.lua
Libs/LibSharedMedia-3.0.lua
Then addon code that uses LibStub("LibSharedMedia-3.0").
LibStub expects WoW's strmatch global; CallbackHandler expects WoW's
securecallfunction; LibSharedMedia expects the WoW/Lua 5.1 globals getfenv,
bit.band, GetLocale, and the client media/API globals used in its source.
Shared media from other addons is available only when registered with the
same LibSharedMedia registry; arbitrary unregistered sound files are not scanned.
